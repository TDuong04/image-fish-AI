# `docs/`: where to read what

| File | What it is |
|---|---|
| `PROGRESS.md` | **The authoritative account.** What was built, findings F1 to F41 with run folders and limits, corrections, bugs, open items |
| `eval_protocol.md` | The evaluation contract: splits, the sealed-set rule, seeds, intervals, pre-declared plans |
| `RESEARCH_STORY.md` | The whole project in narrative form, with mechanisms, a decision log and starter questions (also written to be given to a second AI assistant) |
| `GUIDE.md` | Concepts from the basics: detection, metrics, leakage, TensorRT |
| `RESEARCH.md` | Research narrative, methodology and suggested next steps |
| `MODEL_CARD.md` | The released weights: intended use, data, performance, limits, checksums |
| `hardware.md` | The Jetson Orin Nano: verified facts, corrections and setup |
| `TRAINING.md` | Team setup and training instructions |
| `OVERNIGHT.md` | Runbook for unattended queue runs |
| `data_audit.md` | What is in each dataset and how it was split |
| `PUBLISH_CHECKLIST.md` | Steps before the repository and weights are published |
| `model_manifest.json`, `onnx_manifest.json` | Checksums of checkpoints and ONNX exports |
| `board_probe_20261004.json`, `audit_ozfish_test.json` | Raw output of the board probe and of the sealed-set audit |
| `report/` | Paper drafts (long master and a condensed conference draft), figures and references |
| `tickets/BACKLOG.md` | Tickets (FD-###) and their status |
| `images/` | Pictures and video used in the README |

If a document and `PROGRESS.md` disagree, `PROGRESS.md` wins.
